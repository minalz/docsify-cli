## 📊 神经网络类型对比

| 网络类型 | 核心结构 | 主要特点 | 典型应用场景 | 优势 | 劣势 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **MLP** (多层感知机) | 全连接层堆叠 | 最基础的前馈结构，无特定先验假设 | 表格数据分类/回归、特征融合 | 简单通用、易于实现 | 参数量大、忽略空间/时序结构、易过拟合 |
| **CNN** (卷积神经网络) | 卷积层 + 池化层 | 局部连接、权重共享、平移不变性 | 图像识别、视频分析、医学影像 | 参数量高效、自动提取空间特征、对位移鲁棒 | 对序列/全局关系建模弱、需要大量数据 |
| **RNN** (循环神经网络) | 循环连接，隐藏状态传递 | 具有记忆能力，处理变长序列 | 早期NLP、时间序列预测 | 能处理任意长度序列、参数共享 | 梯度消失/爆炸严重、难以捕捉长距离依赖 |
| **LSTM** (长短期记忆) | 记忆单元 + 门控机制 | 通过遗忘门、输入门、输出门精细控制信息流 | 机器翻译、语音识别、长文本生成 | 有效缓解梯度消失、能建模长期依赖 | 结构复杂、计算开销大、难以并行化 |
| **GRU** (门控循环单元) | 更新门 + 重置门 | LSTM的简化变体，合并门控机制 | 与LSTM类似，资源受限场景 | 参数量更少、训练更快、效果接近LSTM | 表达能力略弱于LSTM、对极长序列建模稍差 |
| **Transformer** | 自注意力 + 前馈网络 | 完全基于注意力机制，无循环/卷积，可并行 | 大语言模型、机器翻译、多模态 | 长距离依赖建模强、高度并行、可扩展性好 | 二次复杂度($O(n^2)$)、需要大量数据/算力 |
| **GAN** (生成对抗网络) | 生成器 + 判别器对抗训练 | 博弈框架，无需显式建模数据分布 | 图像生成、风格迁移、数据增强 | 生成样本质量高、多样性丰富 | 训练不稳定、模式崩溃、难以收敛 |
| **VAE** (变分自编码器) | 编码器 + 解码器 + 隐变量 | 概率生成模型，学习潜在表示分布 | 图像生成、异常检测、表示学习 | 训练稳定、有显式概率解释、可插值生成 | 生成质量通常不如GAN、可能出现模糊结果 |
| **GNN** (图神经网络) | 消息传递 + 邻居聚合 | 专门处理非欧几里得图结构数据 | 社交网络、分子结构、推荐系统 | 能建模关系数据、节点/边/图级别任务灵活 | 深层网络训练难、大规模图计算开销大 |
| **ResNet** (残差网络) | 跳跃连接 (Skip Connection) | 解决深层网络退化问题，可训练极深网络 | 图像分类、检测、分割的骨干网络 | 缓解梯度消失、支持超深网络(1000+层) | 增加内存占用、对浅层网络提升有限 |

## 🎯 快速选型参考

- **图像/视频** → CNN (或基于Transformer的视觉模型如ViT)
- **文本/语音/时序** → Transformer (短序列也可用LSTM/GRU)
- **图/关系数据** → GNN
- **生成任务** → GAN (高质量) 或 VAE (稳定训练)
- **表格/结构化数据** → MLP 或 梯度提升树 (如XGBoost)

> 💡 **提示**：实际选型还需结合数据规模、算力预算、实时性要求等因素综合考量。
