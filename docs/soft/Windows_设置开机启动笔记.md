## 📌 一、Snipaste 设置开机启动

### 方法 1：通过 Snipaste 自带设置（推荐）

1. 在任务栏托盘找到 Snipaste 图标，**右键点击**
2. 选择「**首选项**」（Preferences）
3. 切换到「**常规**」选项卡
4. 勾选「**开机启动**」（Run Snipaste on system startup）
5. 点击「确定」保存

> ⚠️ **注意**：如果勾选了「以管理员身份启动」，可能需要先取消该选项，否则开机启动可能失效。

### 方法 2：通过 Windows 启动文件夹

1. 按 `Win + R`，输入 `shell:startup`，回车
2. 打开开始菜单，找到 Snipaste
3. 右键 Snipaste → 「更多」→ 「打开文件位置」
4. 将 Snipaste 的快捷方式复制/拖入刚才打开的启动文件夹

### 方法 3：通过 Windows 设置

1. 按 `Win + I` 打开「设置」
2. 进入「应用」→「启动」
3. 在列表中找到 Snipaste，将开关设为「开」

> 💡 **提示**：此方法对某些应用可能查不到，属于正常现象。

## 🖥️ 二、通用：Windows 设置任意软件开机启动

### 方式 A：启动文件夹（最可靠）

**打开启动文件夹的几种方法：**

| 方法 | 操作 |
| :--- | :--- |
| Win + R | 输入 `shell:startup`，回车 |
| 完整路径 | `%appdata%\Microsoft\Windows\Start Menu\Programs\Startup` |
| 手动导航 | `C:\Users\你的用户名\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup` |

**操作步骤：**

1. 打开启动文件夹
2. 将需要开机启动的程序的**快捷方式**（.lnk）拖入/复制进去
3. 重启电脑验证效果

> 💡 **提示**：拖入的是快捷方式，不是原程序本身。要取消开机启动，直接从这个文件夹删除对应快捷方式即可。

### 方式 B：Windows 设置

1. `Win + I` →「应用」→「启动」
2. 找到目标应用，打开开关

### 方式 C：任务计划程序（高级）

1. `Win + R` → 输入 `taskschd.msc`，回车
2. 右侧「创建基本任务」→ 设置触发器为「计算机启动时」
3. 指定要启动的程序路径

## ❓ 三、常见问题

| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| `shell:startup` 在 CMD 中报错 | 该命令只能在 Win+R 或资源管理器地址栏使用 | 用 `Win + R` 输入，不要用 CMD |
| 设置了开机启动但无效 | 程序以管理员身份运行 / 被安全软件拦截 | 取消管理员选项，检查防火墙/安全软件 |
| 启动文件夹中找不到 AppData | 文件夹被隐藏 | 资源管理器 →「查看」→ 勾选「隐藏的项目」 |
| 开机启动太慢 | 启动项太多 | 清理启动文件夹，或用任务管理器「启动」选项卡禁用 |

## ⚡ 四、快速启动栏（任务栏快捷图标区）

如果想在任务栏有个快捷启动区域（类似 Win7 快速启动）：

1. 任务栏空白处**右键** →「工具栏」→「新建工具栏」
2. 输入路径：`%appdata%\Microsoft\Internet Explorer\Quick Launch`
3. 在 Quick Launch 左侧竖线分隔符上右键 → 取消勾选「显示文本」和「显示标题」
4. 拖动竖线调整位置到任务栏左侧
5. 把快捷方式拖入该区域即可

## 📝 总结

> 💡 **提示**：优先使用软件自带的开机启动选项，其次用启动文件夹，Windows 设置里的「启动」列表对部分应用不生效。
