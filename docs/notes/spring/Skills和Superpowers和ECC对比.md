## 🧩 二、Skills（技能）—— 基础概念单元

### 1. 定义

Skills 是 AI 编程框架中的**技能定义**，本质上是一段用 Markdown 写的工作流指令，告诉 AI Agent 在特定场景下该怎么做事。

### 2. 特点

- **可复用、可组合**：不同框架都基于 Skill 来扩展能力
- **模块化**：每个 Skill 聚焦一个具体任务
- **标准化**：通常用 Markdown 编写，包含触发条件、执行步骤、检查清单

### 3. 常见 Skill 示例

| Skill 名称 | 用途 |
|:---|:---|
| `brainstorming` | 头脑风暴，澄清需求 |
| `test-driven-development` | 测试驱动开发 |
| `code-review` | 代码审查 |
| `architecture-design` | 架构设计 |
| `security-audit` | 安全审计 |

## 🏎️ 三、Superpowers —— 流程纪律框架

### 1. 项目信息

- **GitHub**: `obra/superpowers`
- **核心理念**: 用精简的 Skill 组合，强制 AI 遵守软件工程纪律

### 2. 规模与特点

| 维度 | 说明 |
|:---|:---|
| Skill 数量 | ~14 个核心 Skill，小而精 |
| 哲学 | **"流程优先，不可跳过"** |
| 强制性 | 强（HARD-GATE 硬门禁） |
| 上手难度 | 低（像自动驾驶） |

### 3. 典型执行流程

```text
头脑风暴 → 写设计文档 → 先写测试 → 子 Agent 开发 → 双阶段审查 → 合并
```

### 4. 核心铁律

1. ✅ 必须先头脑风暴澄清需求
2. ✅ 必须先写失败测试再写生产代码
3. ✅ 必须用 Git Worktree 隔离开发
4. ❌ AI 不能跳过设计直接写代码

### 5. 适用场景

- 严肃项目、严格工程纪律
- 需要标准化开发流程的团队
- 减少 AI "幻觉" 导致的代码质量问题

## 📦 四、ECC（Everything Claude Code）—— 全栈增强工具箱

### 1. 项目信息

- **GitHub**: `affaan-m/everything-claude-code`
- **定位**: Agent Harness 性能优化系统

### 2. 规模与特点

| 维度 | 说明 |
|:---|:---|
| 组件总量 | 300+（30+ Agents、136+ Skills、60+ 命令、50+ 脚本、30+ 钩子） |
| 哲学 | **"全面覆盖，各取所需"** |
| 强制性 | 弱（灵活调用） |
| 上手难度 | 中等（像专业相机） |

### 3. 六大核心组件

#### 3.1 Agents（30+ 子代理）

| Agent | 职责 |
|:---|:---|
| 安全审查员 | 代码安全扫描 |
| 构建错误修复器 | 自动修复编译/构建错误 |
| 测试生成器 | 自动生成测试用例 |
| 文档生成器 | 自动生成代码文档 |

#### 3.2 Skills（136+）

覆盖开发全流程的技能库，比 Superpowers 更庞大但非强制。

#### 3.3 Commands（60+）

用户触发的斜杠命令，如 `/plan`、`/tdd`、`/security-audit`。

#### 3.4 Rules（12+ 语言规范）

多语言编码规范（Python、Java、Go、Rust 等）。

#### 3.5 Hooks（30+）

生命周期自动化钩子，如 `pre-commit` 检查、`post-merge` 通知。

#### 3.6 Scripts（50+）

自动化脚本，用于环境配置、CI/CD 集成等。

### 4. 适用场景

- 多语言项目、开箱即用
- 需要精细化控制的复杂项目
- 希望一站式解决所有 AI 辅助编程需求

## 🎯 七、如何选择？

### 1. 选择 Superpowers 如果

- ✅ 你希望 AI **严格遵守开发流程**
- ✅ 团队需要**标准化、可预测**的输出
- ✅ 项目质量要求**高于开发速度**
- ✅ 希望**低门槛上手**，开箱即用

### 2. 选择 ECC 如果

- ✅ 你需要**多语言、多场景**的全面支持
- ✅ 希望**精细控制**每个环节
- ✅ 项目复杂，需要**子代理分工协作**
- ✅ 愿意投入时间**学习和配置**

### 3. 两者结合

- 有人开发了 `superpowers-ecc` 融合插件
- 结合 Superpowers 的流程纪律 + ECC 的安全扫描、持续学习能力

> 💡 **最佳实践**：用 Superpowers 管流程，用 ECC 补能力。

## 📖 八、关键术语解释

| 术语 | 解释 |
|:---|:---|
| **HARD-GATE** | 硬门禁机制，AI 必须完成某步骤才能进入下一步 |
| **Git Worktree** | Git 功能，允许在同一仓库中并行工作多个分支 |
| **Agent Harness** | 代理控制框架，管理和调度多个 AI 子代理 |
| **TimerWheel** | 时间轮算法，用于高效管理定时/延迟任务 |
| **CommitLog** | 消息持久化日志，RocketMQ 等消息队列的核心存储 |
